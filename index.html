Raincoat

One design-system foundation, compiled to native code for iOS, Android, and the web, with a theme per app.
See the foundationsView on GitHub

A raincoat is the layer that protects you when you are out in the rain. Raincoat is that layer for an app: it keeps accessibility, localization, and consistency intact whatever brand is worn on top.

Status

Milestone 2 is complete, and milestone 3, the v1 components, is in progress: the proposals for its six new components, RFCs 0003 to 0008, are accepted. One token source drives a Button on the web, iOS, and Android, in two themes, published as prereleases to npm, the Maven repository, and the Swift mirror. The releases page says which registries each one has reached, the parity matrix which platforms each component is on, and the roadmap what each milestone delivers.

One source of truth

Design tokens in the DTCG 2025.10 format and platform-neutral component specs. Every platform’s code is generated from them and checked for drift.

Native on every platform

SwiftUI for iOS, Jetpack Compose for Android, and React with shadcn/ui, Radix, and Tailwind CSS for the web.

A theme per app

Apps differ by theme, not by forks. Adding an app means adding a theme, not new components.

Accessible by construction

Every text and border color declares what it sits on, and every pair is checked in light, dark, and both high-contrast modes. See the contrast table.

Built for many languages

Right-to-left layout, long text, Vietnamese, Chinese, Japanese, and Korean are part of every component’s tests.

Free and open source

Apache-2.0. Every dependency must carry a license on the allowlist, and CI fails on anything else.
