Button

In progress

The Button is specified in RFC 0001 and its tokens exist. The React, SwiftUI, and Compose implementations are being built. What you see below is a static rendition, not the component. It is styled only with the custom properties of the generated theme stylesheet, and each panel selects its mode with a data-theme attribute.

Variants

Section titled “Variants”
Variant Use
Primary The main action in a view. At most one per view.
Secondary An alternative action beside the primary one.
Ghost A low-emphasis action with no fill at rest.
Danger A destructive action. Say what is destroyed: “Delete page”, not “Delete”.
