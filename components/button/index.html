3.1

Button

Triggers an action or submits a form.

Spec version 1.2.0, proposed in RFC 0001. The variant and size types used by every platform’s implementation are generated from this spec.

About the renditions

The Button is implemented in React (@raincoat-ui/react), SwiftUI (RaincoatButton), and Compose (RaincoatButton in io.github.raincoat-ui:ui), and ships in the prereleases. The panels under “In every color mode” are static renditions, not the component. They are styled only with the custom properties of the generated theme stylesheet, and each panel selects its mode with a data-theme attribute.

Properties

Section titled “Properties”
Property Values Default Description
variant primary, secondary, ghost, danger secondary How much emphasis the action gets.
size sm, md, lg md The height and text size of the button.
full-width true, false false Stretches the button to the width of its container.
disabled true, false false Makes the button unavailable. It cannot be focused or activated.
loading true, false false Shows that the action is in progress. The label stays and activation is ignored.

Variant

Section titled “Variant”
Value Use
primary The main action in a view. At most one per view.
secondary An alternative action beside the primary one.
ghost A low-emphasis action with no fill at rest.
danger A destructive action, such as deleting.

Size

States

Section titled “States”
State Description
Rest The default appearance.
Hover A pointer is over the button. Exists only where there is a pointer.
Focus visible The button has keyboard focus. The focus ring is shown.
Pressed The button is being pressed.
Disabled The button is unavailable. All variants look the same.
Loading The action is in progress. A spinner is shown and the label stays.

Accessibility

Section titled “Accessibility”
Keys Action
Enter or Space Activates the button.
Tab Moves focus to and from the button. A disabled button is skipped.
Requirement Detail
Role button
Name The label. A button with only an icon must be given an accessible name.
Disabled Not focusable and not activatable. Exempt from contrast requirements.
Loading Stays focusable and keeps focus. Activation is ignored. Assistive technology is told the button is busy: by the busy state on the web and on Android, and on iOS, which has no such state, in words after the name, such as “Save changes, In progress”. On the web, ignoring activation while keeping focus takes a script. In HTML from a server, a busy button is disabled until its script runs, and for good with JavaScript off: until then it cannot be focused, and nothing submits a form through it, not even Enter in a field.
Focus A ring at least 2px wide with 3:1 contrast against the surface behind the button, shown for keyboard focus. On the web and on Android the button draws it from the focus ring tokens. On iOS the system draws its own focus indicator, which follows the person’s Full Keyboard Access settings.
Target size The area that takes touches is at least 44pt on iOS, 48dp on Android, and 44px on a touch screen on the web, whatever the visible size. The button’s layout size is its visible size: around a smaller button the touch area reaches past the container without taking room. On the web and on Android a mouse has to be on the container itself.
Contrast The label has 4.5:1 against the fill in every state, and 7:1 in high-contrast modes.

Internationalization

Section titled “Internationalization”
Concern Behavior
Right to left The leading icon sits on the right and the trailing icon on the left.
Long text The label wraps and the button grows taller. The label is never truncated.
Scripts Line height 1.4 clears stacked Vietnamese diacritics. CJK labels use system fonts.

Guidelines

Section titled “Guidelines”

When to use

Section titled “When to use”

Use a button for an action: saving, submitting, opening a dialog, deleting. To take someone to another page, use a link.

Choosing a variant

Section titled “Choosing a variant”
Variant Use it for Avoid
Primary The one action a view exists for More than one in the same view
Secondary Alternatives to the primary action, such as “Cancel” Using it for the main action
Ghost Low-emphasis actions, often repeated, such as row actions in a table Important actions that must not be missed
Danger Destroying something, such as deleting a project Actions that can be undone trivially

Writing the label

Section titled “Writing the label”
  • Start with a verb: “Save changes”, “Add member”.
  • Use sentence case, not title case.
  • Say what is destroyed on a danger button: “Delete page”, not “Delete”.
  • Do not end with a full stop.
  • Keep it short, but never abbreviate to fit. The label wraps when it has to.

Icons

Section titled “Icons”
  • An icon beside a label is decoration; the label carries the meaning.
  • A button with only an icon must be given an accessible name that says what it does.

Loading and disabled

Section titled “Loading and disabled”
  • Use loading while an action the person started is in progress. The label stays visible so the button’s width and meaning do not change.
  • Prefer leaving a button enabled and explaining what is missing when it is activated. A disabled button cannot say why it is disabled.

Spacing

Section titled “Spacing”

A button takes the room it shows. A button shorter or narrower than the minimum touch target still takes touches across that minimum, so its touch area reaches a few pixels past its edges.

  • Leave at least 8px (space.2) between small buttons, so that the touch area of one button never covers part of another.
  • Between two buttons that close, the touch areas can share the gap. Android gives a touch there to the nearer button; on iOS and the web, do not count on which one gets it.
  • Do not rely on the touch area to separate a small button from other content. Give it the spacing you would give any control.

Do and don’t

Section titled “Do and don’t”
Do Don’t
Put the primary action last in a group in left-to-right layouts Put two primary buttons side by side
Keep button order the same across a product Change which side “Cancel” is on between dialogs
Let long labels wrap Truncate a label with an ellipsis
