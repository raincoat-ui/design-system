# 0012. The name Raincoat

- Status: accepted
- Date: 2026-11-14

## Decision

The system is called Raincoat: a layer that protects you when you are out in the rain. For an
app, the system is that layer.

| Where  | Identifier                                                                                   |
| ------ | -------------------------------------------------------------------------------------------- |
| GitHub | Organization `raincoat-ui`, repository `raincoat-ui/design-system`                           |
| npm    | Scope `@raincoat-ui`: `@raincoat-ui/react`, `@raincoat-ui/tokens`, `@raincoat-ui/theme-<id>` |
| Maven  | Group `io.github.raincoat-ui`                                                                |
| Swift  | Products `Raincoat`, `RaincoatTokens`, `RaincoatTheme<Id>`                                   |

## Context

On the day of this record, no design system or UI library named Raincoat appeared in
awesome-design-systems or in a web search. Trademark registers were not checked.

## Consequences

- The organization name appears in URLs and identifiers that consumers hard-code, so it should
  not change.
