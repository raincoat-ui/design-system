2.2

Contrast

Every text, border, and focus color declares what it is drawn on. The build computes the WCAG 2 contrast ratio of each pair in each color mode and fails if any pair is below its requirement.

Kind Standard modes High-contrast modes
Text 4.5:1 7:1
Large text (24px and above) 3:1 4.5:1
Outline or icon 3:1 3:1

All 524 checks pass. The table lists each pair’s ratio.
